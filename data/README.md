# Required data and metadata

No video, extracted feature, real annotation, train/test split or weight is supplied here.
Copy the actual `data_info.json` used for your experiments, or pass it with `--data-info`.
The JSON is an object keyed by `THUMOS`, `CrossTask`, and/or `TVSeries`. Each dataset entry must contain:

| Key | Content |
|---|---|
| `data_root` | Dataset directory; publication launcher `--data-root`/config path takes precedence |
| `class_names` | Complete ordered class list including background and any ignored class |
| `num_classes` | Length of the ordered list; must match target width |
| `ignore_index` | Actual ignored class index used by the original evaluation |
| `metrics` | `AP` or `cAP`; explicit release configs override it consistently |
| `fps` | Actual feature-token FPS |
| `train_session_set` | Exact training video ID stems |
| `test_session_set` | Exact evaluation video ID stems; hold-out validation for selection, official test for final evaluation |

The three subdirectories selected by `INPUT.VISUAL_FEATURE`, `INPUT.MOTION_FEATURE` and `INPUT.TARGET_PERFRAME` contain one `.npy` per ID.

THUMOS ResNet RGB/flow dimensions: 2048/1024; DINOv3 RGB: 4096. CrossTask inputs: 1024/2176. TVSeries RGB/flow/targets: `[L,2048]`, `[L,1024]`, `[L,31]`, with `target_perframe_drop_oob` used by both release variants. This package cannot infer whether your arrays were generated by the final processing policy; verify their provenance separately.

For TVSeries, reuse the already verified 27-episode extraction output. The final two-policy label processing and DenseFlow repair utilities were not in the supplied model folder and are not replaced with the older root-level preprocessing scripts.

Do not generate new random splits to fill missing historical metadata. Do not redistribute restricted original video files. If publishing processed data, document source licenses, array layout, label policy and checksum manifest.
